Decisões Tomadas Autonomamente

1. Interface brave-search.sh compatível com surf-search-normal
Mesmas flags (--task, --goal, --insights, --deliverable, --json) para migração zero-atrito. Sub-agentes não precisam aprender nova interface.
2. Evolução de queries heurística (não LLM)
A evolução usa algoritmo de contagem de palavras + sufixos rotativos, sem depender de LLM. Mais rápido (sem round-trip de API), sem custo de tokens.
3. BRAVE_API_KEY como variável de ambiente
Scripts leem do ambiente, consistente com outras credenciais. Sem arquivo de config separado.
4. CREDITS_LOW = sem créditos (com --fail-fast)
Interpretação conservadora: se há menos de 100 créditos, trata como insuficiente. Evita que sub-agentes comecem e falhem no meio.
5. System-ui como fonte (Google Fonts sem SRI)
HTML explainer usa system-ui para manter integridade SRI. Google Fonts não oferece hash de integridade.
6. Template HTML com placeholders begin/end (não só tokens)
Slots com marcadores de bloco permitem substituir seções inteiras (ex: tabela de ondas), não só valores pontuais.
